# 强化学习井字棋 (RL Tic-Tac-Toe)

使用强化学习（Q-Learning）训练的修改版井字棋游戏。

## 游戏规则

这是一个特殊的井字棋变体，规则如下：

1. **棋盘**: 3x3 的棋盘
2. **玩家**: 两个玩家轮流下棋
3. **胜利条件**: 在一**列**上连成一条线即可获胜（注意：在一**行**上连成线**不算**胜利）
4. **棋子数量**: 每个玩家有 3-4 个棋子
5. **特殊动作**: 在自己的回合，玩家可以选择不下棋，而是移除棋盘上的一个对方棋子
6. **移除机会**: 每个玩家在整场游戏中有最多两次移除对方棋子的机会
7. **棋子回收**: 被移除的棋子会回到对方的"仓库"中，可以被对方在之后的回合中重新放置在棋盘上

cd rl_tic_tac_toe

## 使用方法

### 0. 快速演示

运行演示脚本查看所有功能：

```bash
python demo.py
```

这将展示：
- 游戏规则和机制
- 训练好的智能体对战演示
- 性能统计

### 1. 训练智能体

运行训练脚本：

```bash
python train.py
```

训练选项：
- **选项 1**: 对抗随机对手训练（更快，适合快速测试）
- **选项 2**: 自我对弈训练（更稳健，两个智能体互相学习）

训练参数：
- 训练回合数（默认：10000）
- 每个玩家的棋子数（3 或 4，默认：4）

训练完成后，模型会保存为：
- `trained_agent_p1.pkl` - 玩家1的训练模型
- `trained_agent_p2.pkl` - 玩家2的训练模型（仅自我对弈模式）

### 2. 游戏演示

运行游戏脚本：

```bash
python play.py
```

可用选项：
1. **人类对战AI（人类先手）**: 你先下棋
2. **人类对战AI（AI先手）**: AI先下棋
3. **观看AI对战AI（单局）**: 观看两个训练好的AI对战
4. **观看AI对战AI（多局）**: 观看多局比赛并显示统计
5. **测试AI对战随机对手**: 评估训练效果
6. **退出**

### 3. 游戏界面说明

棋盘显示：
```
  0 1 2
0 . . .
1 . X .
2 O . .

Current player: X
Reserve - X: 3, O: 2
Removals left - X: 2, O: 1
```

- `.` - 空格
- `X` - 玩家1的棋子
- `O` - 玩家2的棋子
- Reserve - 每个玩家仓库中剩余的棋子数
- Removals left - 每个玩家剩余的移除机会

## 技术实现

### Q-Learning 算法

本项目使用 Q-Learning，一种无模型的强化学习算法：

- **Q值更新规则**: Q(s,a) = Q(s,a) + α * [r + γ * max Q(s',a') - Q(s,a)]
- **学习率 (α)**: 0.1
- **折扣因子 (γ)**: 0.95
- **探索率 (ε)**: 从 1.0 衰减到 0.01

### 状态表示

游戏状态包括：
- 棋盘状态（9个位置）
- 当前玩家
- 每个玩家的仓库棋子数
- 每个玩家剩余的移除机会

### 动作空间

每个回合，玩家可以：
- 在空位上放置一个棋子（如果仓库有棋子）
- 移除对手的一个棋子（如果还有移除机会）

### 奖励机制

- 获胜: +1
- 失败: -1
- 平局: 0

## 示例：快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 查看演示
python demo.py

# 3. 训练智能体（快速模式，5000回合）
python train.py
# 选择选项 1（对抗随机对手）
# 输入 5000 作为训练回合数
# 输入 4 作为每个玩家的棋子数

# 4. 开始游戏
python play.py
# 选择选项 1（人类对战AI）
```

## 性能

训练 5000-10000 回合后：
- 对抗随机对手的胜率通常可达到 **20-30%**，平局率 **60-75%**
- 自我对弈训练的模型更加稳健，能应对各种策略
- Q-table 通常包含 15000-20000 个状态-动作对

## 自定义训练

你可以在代码中调整以下参数：

在 `agent.py` 中：
- `learning_rate`: 学习率
- `discount_factor`: 折扣因子
- `epsilon`: 初始探索率
- `epsilon_decay`: 探索率衰减速度

在 `train.py` 中：
- `num_episodes`: 训练回合数
- `pieces_per_player`: 每个玩家的棋子数（3-4）
