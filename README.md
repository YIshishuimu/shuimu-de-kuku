## Projects

### 井字棋AI训练系统 (Tic-Tac-Toe AI Training)

基于Q-learning强化学习算法的井字棋AI训练系统。

**快速开始:**
```bash
# 安装依赖
pip install -r requirements.txt

# 运行演示
python demo.py

# 基础训练 (胜率 45-48%)
python train_model.py

# 高级训练 - 自我对弈 (胜率 50-60%+) 🌟
python train_advanced.py

# 超级训练 - 集成所有优化 (胜率 70-80%+) 🚀
python train_ultra.py

# 与AI对战 (可视化界面) 🎮
python play_visual.py

# 与AI对战 (简单版)
python play_game.py
```
