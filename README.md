## Projects

### 井字棋AI训练系统 (Tic-Tac-Toe AI Training)

基于Q-learning强化学习算法的井字棋AI训练系统。

**快速开始:**
```bash
# 安装依赖
pip install -r requirements.txt

# 运行演示
python demo.py

# 训练模型
python train_model.py

# 与AI对战
python play_game.py
```
